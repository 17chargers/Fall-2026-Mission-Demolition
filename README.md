# Fall 2026 Mission Demolition

**Timothy Rogers**

## Making the Game Cooler

For the final point of this project, I added a **star system** that rates the player based on how many shots it took to beat each level. Each level allows a maximum of **5 shots** before the player loses.

### Scoring

| Stars | Shots needed |
|:-----:|:-------------|
| 3 stars | 2 shots or fewer |
| 2 stars | 4 shots or fewer |
| 1 star | 5 shots |

### Winning Screen

At the end of the game, if the player successfully beats all 4 levels, a winning screen pops up showing how many of the **12 total available stars** they earned. It also gives the player the option to play again.
